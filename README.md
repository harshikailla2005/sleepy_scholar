# 🎓 Sleepy Scholar - Student Management System

A modern, full-stack web application for managing student records using a Node.js API and MySQL.

## 🚀 Features
- **Glassmorphic UI:** Modern GenZ aesthetic with neon glows and dark mode.
- **Secure Login:** Authentication system linked to MySQL.
- **Student Management:** Create and View student records in real-time.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MySQL

## 📋 Installation
1. Clone the repo: `git clone https://github.com/YOUR_USERNAME/sleepy-scholar.git`
2. Install dependencies: `cd student-backend && npm install`
3. Import the `sleepy_scholar1.sql` file into your MySQL database.
4. Run the server: `node server.js`
